점검 대상 프롬프트:

<prompt>
$ARGUMENTS
</prompt>

다음 절차를 순서대로 따른다.

1. `docs/PROMPT_GUIDE.md`를 읽는다.
2. 위 프롬프트를 가이드의 4개 항목(토큰 효율, 명확성, 완결성, 구조)별로 10점 만점 채점한다. 완결성은 목표·제약·완료 기준·출력 형식 4요소 기준으로 본다.
3. 8점 미만 항목에 대해서만 보완점을 제시한다. 모호어는 가이드 2장의 대체 표현을 쓰고, 작업 유형에 맞는 기법(직접 지시/CoT/ToT)을 가이드 3장에서 고른다.
4. 보완점을 반영한 프롬프트를 작성한다.
5. 여기서 멈추고 승인을 기다린다. 사용자가 승인하면 보완된 프롬프트를 실행한다. 승인 전에는 파일 수정이나 명령 실행을 하지 않는다.

출력 형식 (이 3개만 출력):

1. **점수 표**: 항목 | 점수 | 근거(1줄)
2. **보완점**: 3줄 이내 (모든 항목이 8점 이상이면 "보완 불필요")
3. **보완된 프롬프트**: 코드 블록 1개

마지막 줄: `이대로 실행할까요? (승인 / 수정 요청)`
